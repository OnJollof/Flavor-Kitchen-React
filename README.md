# Flavour Kitchen

## Project Description
A responsive restaurant website built with React JS. Visitors can read about the
restaurant, browse and filter the menu, add dishes to a cart, and send a message
through a validated contact form.

## Technologies Used
- React JS (functional components, props, useState, useEffect)
- React Router
- Vite
- JavaScript, HTML, CSS (Flexbox, Grid, media queries)

## Installation
1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Run: `npm install`
4. Start the application: `npm run dev`

## Live Demo
https://flavorkitchen01.netlify.app

## Deployment note
On Render (Static Site), add a rewrite rule: `/*` -> `/index.html` (Rewrite).
